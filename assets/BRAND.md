# Intelligent Masking

I와 M을 결합한 자체 심볼이다. M의 하단을 가르는 두 개의 여백은 문서의 마스킹 구간을 표현한다.

- 심볼: `brand-symbol.svg` — 웹사이트 헤더와 파비콘
- 가로 로고: `brand-logo.svg` — 발표 자료와 문서에 사용
- 대표 이미지: `brand-avatar.png` — 기존 심볼을 여백이 있는 정사각형 PNG로 내보낸 GitHub 조직용 이미지
- 청록 `#009D8A`, 연두 `#8ADD79` — iM뱅크 공식 홈페이지의 상단 색감을 참고
- 진한 청록 `#007768` — 글자가 있는 주요 버튼
- 잉크 `#193B36`, 배경 `#F3F6F8` — 제목과 작업 공간

공식 은행 로고를 재사용하지 않고 만든 프로젝트 로고다. SVG는 투명 배경이며 크기를 바꿔 사용할 수 있다.

## 타이포그래피

제목·설명·상단 메뉴는 iM뱅크 홈페이지의 Noto 계열을 참고한 Noto Sans KR을 사용한다. 제목 굵기는 700(50px), 설명은 500(20px), 일반 메뉴는 400, 선택 메뉴는 500이다. 데스크톱 메뉴 18px, 프로젝트 표시 14px, 모바일 메뉴 14px로 설정했다.

폰트는 현재 제목·메뉴 문구에 해당하는 글자만 포함한 로컬 UI 서브셋이다. 이 문구를 바꾸면 Noto 폰트 파일도 다시 생성한다. SIL OFL 라이선스는 `fonts/NotoSansKR-LICENSE.txt`에 포함했다. Pretendard Variable은 대체 글꼴로 유지한다.

본문 바탕은 iM뱅크 공식 홈페이지에서 확인한 #F3F6F8을 적용했다. 업로드 영역은 중립적인 연회색, 카드와 하단은 흰색으로 정리했다.
